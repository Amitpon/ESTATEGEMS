## הערות אימות - קרא לפני שימוש

**האתר החי `estate-gems.base44.app` מוגן בסיסמה ולא היה נגיש.** כל מה שנאמר כאן על
המוצר הקודם מבוסס על `docs/research/estategems-teardown.md`, לא על צפייה ישירה.

**שמות השדות אומתו על ידי ה-PM** מול `src/lib/calc/projection.ts`, `mortgage.ts`
ו-`src/types/property.ts`. הם מדויקים. תיקון אחד למסמך המקור: `scenarioSpreadPoints`
ברירת המחדל היא **2**, לא 1.5.

## 1. הפער שחוסם את הבקשה המרכזית

בעל המוצר ביקש "כמה נרוויח אם נמכור בכל שלב". `ScenarioYear` כבר מכיל את רוב מה
שצריך, אבל **חישוב מס שבח ורווח נטו ממכירה לא קיימים במנוע**.

נדרש `src/lib/calc/capital-gains.ts` (בעלות: calc-engine). **אסור לממש אותו לפני
שמחקר המס חוזר** - ראה `docs/research/capital-gains-tax.md` כשייכתב. כלל 18 החודשים
שבעל המוצר תיאר טרם אומת.

עד אז: שדה מס שבח בטבלה הוא **קלט ידני** עם ברירת מחדל, מסומן "הנחה שלך".

---

## 2. מה כבר קיים במנוע

`ScenarioYear` (מאומת) - לכל שנה בהרצה:

| שדה | משמעות |
|---|---|
| `year` | מספר השנה, מ-1 |
| `propertyValue` | שווי הנכס בסוף השנה, מעוגל גס |
| `monthlyRent` | שכר הדירה החודשי באותה שנה |
| `annualNetCashflow` | התזרים הנקי השנתי |
| `cumulativeNetCashflow` | התזרים המצטבר מתחילת ההרצה |
| `mortgageBalance` | יתרת המשכנתא בסוף השנה |
| `equityInProperty` | ההון בנכס - שווי פחות יתרה |

`ScenarioRun` מחזיק `central` / `low` / `high`, את `horizonYears`, את `assumptions`
ואת `disclaimer` - **נוסח מוכן שהממשק חייב להציג**, עיקרון 1.

## 3. טבלת "מכירה בכל שנה" - העדיפות הראשונה

### עמודות

| עמודה | מקור |
|---|---|
| שנה | `year` |
| שווי הנכס | `propertyValue` |
| יתרת משכנתא | `mortgageBalance` |
| הון בנכס | `equityInProperty` |
| תזרים מצטבר | `cumulativeNetCashflow` |
| רווח הון ברוטו | `propertyValue - input.property.price` |
| מס שבח | **חסר במנוע** - קלט ידני בינתיים |
| עלויות מכירה | הנחה ניתנת לעריכה (מתווך + עו"ד) |
| רווח נטו ממכירה | הון בנכס פחות מס פחות עלויות מכירה |
| **רווח כולל** | רווח נטו ממכירה + `cumulativeNetCashflow` |
| **תשואה שנתית ממוצעת** | `(רווח כולל / equity.investedCapital) / year * 100` |

שתי העמודות האחרונות הן מה שבעל המוצר ביקש: "כמה אחוזים מרוויחים בסך הכל ובממוצע לשנה".

### כותרת חובה - עיקרון 1

```
לפי ההנחה שלך: עליית ערך [assumedAppreciationPct]% בשנה
אלה הרצות של ההנחות שלך, לא תחזית
```

אסור "רווח צפוי". מותר "רווח לפי ההנחות שהזנת". כל מספר עתידי מעוגל גס.

### האבחנה על המינוף

בעל המוצר הצביע על כך שכשהמשכנתא גבוהה מהשכירות, ממשיכים להזרים כסף כל חודש, ולכן
התשואה באחוזים גבוהה יותר בשנים המוקדמות - המינוף בשיא, וההון העצמי שנצבר עדיין קטן.
**עמודת התשואה השנתית הממוצעת מראה בדיוק את זה** ולכן היא חשובה יותר מעמודת הרווח
בשקלים. הממשק מציג את המספרים; הוא לא מסיק מהם מסקנה ולא ממליץ מתי למכור.

### ממשק

- **390px:** כרטיסייה לשנה - שווי, רווח כולל, תשואה שנתית. `[פרטים]` פותח את השאר
- **768px+:** טבלה מלאה עם scroll אופקי
- **שורת `horizonYears`** מודגשת
- **הדפסה:** `break-inside: avoid` כל 5 שורות

## 4. הגרפים

**כלי:** `d3-scale` + `d3-shape` + SVG ידני. **לא recharts** (`dependency-audit.md`).

**כלל RTL לכל הגרפים:** ציר X (זמן) נשאר **LTR** - שנה 1 בשמאל. ציר Y עובר **לימין**.
אגדה מיושרת לימין.

### 4.1 הרצת ההנחות - העדיפות השנייה

Area chart עם רצועת תרחישים.

- **X:** שנים 1 עד `horizonYears`, LTR, טיק כל 5 שנים
- **Y (ימין):** שקלים, תוויות מקוצרות ("2.3 מיליון", לא "2,300,000")
- **רצועה:** `low.years[n].propertyValue` עד `high.years[n].propertyValue`
- **קו מרכזי:** `central.years[n].propertyValue`
- **קו הון:** `central.years[n].equityInProperty`, מקווקו. **נסתר במובייל**
- **כותרת:** ההנחות שיצרו את הגרף, כל אחת סליידר
- **מובייל:** גובה 220px, 3 תוויות Y בלבד

### 4.2 תזרים לאורך זמן

Bar chart. X = שנים (LTR). Y = `annualNetCashflow`. ירוק לחיובי, אדום לשלילי.
קו `cumulativeNetCashflow` מקווקו, נסתר במובייל. גובה מובייל 160px.

### 4.3 רווח ממכירה לאורך זמן

הגרף שמלווה את טבלת סעיף 3. שני קווים: `equityInProperty` ו-`cumulativeNetCashflow`.
נקודת ההצטלבות מסומנת ויזואלית - שם התזרים המצטבר משתווה להון בנכס.

### 4.4 קרן מול ריבית

Stacked area מ-`mortgage.combinedRows`: `row.principal` ו-`row.interest`.
X = חודשים, טיק כל 60. לא בדוח המודפס כברירת מחדל.

### 4.5 השוואת מסלולי מס שכירות

Bar אופקי, 3 עמודות מ-`rentalTax.tracks` לפי `annualTax`. המסלול ב-`rentalTax.selected`
מסומן. המסלולים כבר ממוינים מהזול לגבוה - **זו השוואה, לא המלצה**.

## 5. הסליידרים

debounce 150ms. **בעיית RTL:** `<input type="range">` לא עקבי בין דפדפנים ב-RTL.
הפתרון: `[dir="rtl"] input[type="range"] { transform: scaleX(-1); }` והיפוך חוזר
על תווית הערך.

| סליידר | שדה | טווח | צעד | ברירת מחדל |
|---|---|---|---|---|
| עליית ערך שנתית | `assumptions.assumedAppreciationPct` | 0-12% | 0.5 | 3% |
| עליית שכ"ד שנתית | `assumptions.assumedRentGrowthPct` | 0-8% | 0.5 | 2% |
| עליית הוצאות | `assumptions.assumedExpenseGrowthPct` | 0-8% | 0.5 | - |
| מדד תשומות בנייה | `assumptions.assumedIndexChangePct` | 0-10% | 0.5 | - |
| אופק ההרצה | `assumptions.horizonYears` | 1-30 | 1 | 10 |
| רוחב הטווח | `assumptions.scenarioSpreadPoints` | 0-4 | 0.5 | **2** |
| אי-אכלוס | `input.income.vacancyPct` | 0-20% | 1 | `DEFAULT_VACANCY_PCT` |
| ריבית | `LoanTrack.annualRatePct` | 1-12% | 0.1 | - |
| תקופה | `LoanTrack.termMonths` | 60-360 | 12 | 360 |

**תווית: "ההנחה שלך", לא "תחזית".**

**מובייל:** thumb מינימום 24x24px, שורה 60px, בתוך accordion.

**עוגן מומלץ:** לצד מדד תשומות הבנייה להציג את הנתון האמיתי מלמ"ס (103.9, +3.5%
שנתי, אוגוסט 2026 - ראה `property-data-sources.md`). **עוגן, לא מילוי אוטומטי.**

## 6. לוח הסילוקין

מקור: `mortgage.combinedRows`, אורך `mortgage.maxTermMonths`. **360 שורות מלאות ללא
קטימה** - EstateGems קטם ל-120 וזה תוקן.

**שתי תצוגות:**
- **שנתי (ברירת מחדל):** קיבוץ כל 12 חודשים. 30 שורות. יתרה = `balance` של החודש ה-12
- **חודשי:** 360 שורות, 24 לעמוד

**עמודות:** תקופה, תשלום, קרן, ריבית, יתרה. כל מספר `tabular-nums` ו-`dir="ltr"`.

**מובייל:** עמודת "תשלום" נסתרת (נגזרת מקרן+ריבית). ניווט pagination עם יעד מגע 44px
ושדה "קפוץ לשנה".

**הדפסה:** תצוגה שנתית בלבד, 30 שורות.

## 7. ההשוואות

### 7.1 בין נכסים
עד 5 נכסים, כל אחד ריצת `analyze()` נפרדת עם **אותן `Assumptions`**.
מדדים: כל `metrics.ordered`, בתוספת `propertyValue` ורווח כולל בשנה N.

- **390px:** כרטיסיות scroll-snap ברוחב 85%
- **768px+:** טבלה, עמודת שם המדד sticky

**אסור לסמן "המוביל" או "המומלץ"** - עיקרון 1. מותר להדגיש את הערך הגבוה ביותר
בכל שורה כעובדה.

### 7.2 בין תרחישים - ניתוח רגישות
בוחרים פרמטר אחד וסורקים 2-6 ערכים. פלט: טבלה, שורה לערך.
פרמטרים: עליית ערך, עליית שכ"ד, שכר דירה, ריבית, אי-אכלוס.

## 8. לוח תשלומים מקבלן

מוצג **רק** כש-`analysis.paymentSchedule !== undefined`.

עמודות מ-`paymentSchedule.stages`: `label`, `dueDate`, `percentOfPrice`,
`nominalAmount`, `indexFactor` (רק אם `indexed`), `indexationAmount`, `payableAmount`.

סיכום: `totalNominal`, `totalIndexation`, `totalPayable`.
כותרת: `לפי ההנחה שלך: שינוי מדד [assumedIndexChangePct]% בשנה`.

**תוספת נדרשת - תאריך אכלוס.** בעל המוצר ביקש שדה תאריך אכלוס לדירה על הנייר,
כי ממנו נגזרת זכאות הפטור ממס. **השדה לא קיים ב-`PaymentScheduleInput`** ודורש
תוספת ב-calc-engine, אחרי שמחקר המס יקבע ממה בדיוק נספרים 18 החודשים.

**מובייל:** 4 עמודות - תאריך, אחוז, נומינלי, לתשלום. השאר ב-expand.

## 9. הדוח המודפס

`window.print()` + print stylesheet. **לא** html2canvas - שבורה בעברית.

| עמוד | תוכן |
|---|---|
| 1 | כרטיס זהות + מדדים מרכזיים + `scenarios.disclaimer` |
| 2 | פירוק תזרים (מ-`cashflow`) + עלויות יום 1 (מ-`equity.lines`) |
| 3 | לוח סילוקין שנתי |
| 4 | גרף ההרצה + טבלת מכירה בכל שנה |
| 5 | לוח תשלומים מקבלן - רק אם קיים |

```css
@media print {
  .no-print { display: none !important; }
  .card { box-shadow: none; border: 1px solid #ccc; }
  .print-break-after { break-after: page; }
  .print-no-break { break-inside: avoid; }
  .tabular-nums { font-variant-numeric: tabular-nums; }
}
```

**חובה בכל עמוד:** תאריך ההפקה, וה-`disclaimer` מה-`ScenarioRun` בעמוד הראשון.

## 10. סדר מימוש

1. **טבלת מכירה בכל שנה** - הבקשה המרכזית. חסום חלקית על מס שבח, אפשר להתחיל עם קלט ידני
2. **גרף ההרצה** - כל הנתונים קיימים, ציור SVG בלבד
3. **סליידרים** - state בלבד, המנוע מהיר
4. **לוח סילוקין** - הנתונים קיימים, צריך pagination ותצוגה שנתית
5. **דוח מודפס** - print stylesheet
6. **השוואות** - מסך וניהול state

**חסום עד שמחקר המס חוזר:** `capital-gains.ts`, שדה תאריך אכלוס, וכל מספר מס שבח.
